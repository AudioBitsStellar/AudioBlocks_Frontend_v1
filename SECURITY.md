# Security Policy

## Supported versions

Security fixes are made against the `main` branch. Older release tags are not patched.

## Reporting a vulnerability

Please do not open a public GitHub issue, pull request, or discussion for a security problem.

Report it privately through GitHub's private vulnerability reporting:

https://github.com/AudioBitsStellar/AudioBlocks_Frontend_v1/security/advisories/new

Include, where you can:

- A description of the issue and its impact.
- Steps to reproduce, with the affected URL, file, or commit.
- Any suggested fix.

Do not include real user data, private keys, or wallet secrets in a report. Test only against accounts and data you own.

## Response time

- **Acknowledgement:** within 3 business days of your report.
- **Triage:** within 7 business days, including a severity assessment and whether we accept the report.
- **Updates:** at least every 14 days until the issue is resolved.
- **Fix target:** we aim to ship fixes for confirmed critical and high severity issues within 30 days.

We will credit reporters in the advisory unless they ask to stay anonymous.
